# Bitcoin Treasury Tracker

Static site (`site/`) + data script (`scripts/update.mjs`) + GitHub Actions workflow that refreshes `site/data.json` every ~15 min and deploys to GitHub Pages. No API keys, no dependencies.

## Add a company
Append an entry to `config/companies.json` (see `_readme` there). If CEBE Tracker covers it, set `cebeTicker`; otherwise fill `manual` with btc_holdings, debt_usd, preferred_usd, cash_usd, basic_shares, as_of, source from the latest filing.

`filings` turns on a freshness check. The figures stay on the CEBE or manual values.

- `{"source":"sec","cik":"0001050446"}` records the latest 8-K, 8-K/A, 10-Q, 10-Q/A, 10-K, or 10-K/A from EDGAR, and the page links to that filing. The script checks the CIK on EDGAR (the company-ticker list when that file is reachable, and the submissions record’s CIK and tickers) and skips the filing if they do not match. Optional `ticker` overrides `ticker` when the EDGAR symbol differs from the display ticker. A legacy `sec_cik` (and optional `sec_ticker`) still selects this check.
- `{"source":"metaplanet","url":"https://metaplanet.jp/en/shareholders/disclosures"}` reads Metaplanet’s TDnet disclosure list. Metaplanet does not file with the SEC. `url` is optional and defaults to that page (`source` may also be `"tdnet"`). The page redirects to `/en/disclosures`.

CEBE feed tickers today: MSTR, MTPLF, ASST, TSWCF, ALCPB, OBTC3, SVIA, NAKA, DDC, HOGPF, XXI, CASH3.

## Run locally
    node scripts/update.mjs && npx serve site   # or: python3 -m http.server -d site
    node --test                                  # filing-date comparison and disclosure parsing, no network

## Deploy (GitHub Pages)
1. Create a public GitHub repo, push this folder to `main`.
2. Repo Settings → Pages → Source: **GitHub Actions**.
3. Actions tab → run "Update data & deploy" once. Site: https://<user>.github.io/<repo>/
The workflow rewrites `style.css` and `app.js` in the deployed `index.html` with a content hash (`?v=`), so a browser that cached the previous script cannot render a newer page. `app.js` loads `data.json` with a unique query and `cache: 'no-store'`.
The same workflow commits `data/share-history.json` when a company has a new `as_of` (or a revised count for an `as_of` already stored) and `data/institutional-ownership.json` when that cache is refreshed. The commit message includes `[skip ci]`, and the push trigger ignores those paths, so the commit does not start another run. The job’s `contents: write` permission is what allows that push. `site/data.json` is not committed by the job; it is deployed with the site. The job installs `poppler-utils` so `pdftotext` can read Metaplanet shareholder PDFs.
Note: GitHub disables scheduled workflows in public repos after 60 days with no repo activity; push any commit (or re-enable in the Actions tab) to resume.

## Data sources
- Balance sheet (BTC held, debt, preferred, cash, basic shares) + CEBE construction: CEBE Tracker open feed https://cebetracker.io/api/v1/companies.json — free with attribution ("Data via CEBE Tracker, cebetracker.io"), which the page displays.
- **Share-count override.** `share_count` on a company (`basic_shares`, `as_of`, `source`, `url`) replaces CEBE's basic shares while that `as_of` is newer than CEBE's `as_of`. Market cap, basic mNAV, EV mNAV, residual NAV/share, the CEBE mNAV figure computed on this page, shares outstanding, and Δ Shares all use it. CEBE Tracker's own published mNAV is unchanged and is labelled “CEBE share count” when an override is in effect. Once CEBE's date is the same or newer, the feed is used again. Metaplanet's override is the Oct 14, 2026 ToSTNeT-3 buyback: 73,981,400 shares at ¥261 held as treasury (TDnet 140120261014550251), so outstanding is 1,290,274,296 = issued 1,364,282,624 − treasury 74,008,328. The same override subtracts the ¥19,309,145,400 spent from CEBE cash and adds that USD amount to CEBE net claims, because residual NAV is BTC value minus net claims, then divided by the share count. Both the share count and the cash adjustment stop when CEBE's date catches up. A later treasury-acquisition result notice on the disclosures page logs a warning. The MPJPY display quote is unchanged; mNAV still uses the 3350.T price.
- **Δ Shares** compares the basic count in Shares outstanding with the count at the previous reporting date (the prior distinct `as_of` for that company). The feed only publishes the latest snapshot, and a Pages artifact is not kept for the next run, so `scripts/update.mjs` stores one row per company per `as_of` in `data/share-history.json`. A repeated run with the same `as_of` and the same count does not append a row. An increase is ▲ and the shares added (for example ▲ 140,872), a decrease is ▼ and the shares removed, and the same count is Unchanged. The muted line under the figure is the previous count's as-of date (for example vs Oct 11). With no earlier row the cell is — and “no prior count yet”. The arrows stay in the table’s normal text color. **% Δ Shares** is that change divided by the previous basic count, in the same column style (▲, ▼, or Unchanged, plus the same “vs” date) and the same text color. It shows two decimals (▲ 1.41%). A non-zero move that would round to 0.00% is shown as &lt;0.01%. Metaplanet uses its Tokyo basic share count for both columns, the same count as Shares outstanding, not a US listing. Seeded priors, each checked against the filing named in that row’s `source`: Strategy 422,118,949 as of 2026-10-11; Strive effective common shares 110,387,204 as of 2026-10-09 (CEBE’s latest `as_of` is 2026-10-20, the SATS closing, while the share count is still the 2026-10-16 figure); Metaplanet 1,345,313,741 issued shares excluding treasury as of 2026-08-31.
- **Institutional ownership** = institutional shares ÷ the basic shares outstanding shown in that row. The muted line is the holdings as-of date (for example 13F Jun 30). The figure is a button: hover or focus opens the holder detail, and a tap opens it on a phone. Holders above 5% of those basic shares are listed with name, shares, percent, and source. If none are above 5%, the detail says so and lists the three largest reported holders. `scripts/update.mjs` stores the last good fetch in `data/institutional-ownership.json` and refreshes a company only when `attempted_at` is at least 20 hours old. A failed fetch keeps the saved shares and still shows their as-of date.
  - US companies (`filings.source` `"sec"`): the numerator is Nasdaq’s Form 13F institutional-holdings total (`https://api.nasdaq.com/api/company/{ticker}/institutional-holdings`). The request sends a browser User-Agent and `Accept: application/json`. Nasdaq’s own percent is ignored. It is an unofficial endpoint; if it fails, the saved total is kept. Holders above 5% also use the latest Schedule 13D/13G/A on EDGAR for that CIK. The later as-of date wins when the same holder appears in both. Separate legal entities that share a name (for example several Vanguard filers) are not added together; the detail says so. A 13D/13G whose implied shares outstanding are a different order of magnitude from the current basic count (a split or a pre-merger capital structure) is dropped. EDGAR requests use the same User-Agent and one-request-per-second spacing as the filing check.
  - Metaplanet: Japan has no 13F total of institutional shares. The cell is a floor, labelled “≥5% institutional filers (Japan large-holding reports)”: Capital Research and Management Company’s 143,301,084 shares are 1,433,010 ÷ 12,894,494 voting rights, 11.11% (shown as 11.1%) as of 2026-10-16, Change Report No. 31 (notice 140120261023555451). The detail still lists holders above 5% of current basic shares from the latest English major-shareholder notice and the shareholder register. It also shows an owner-type estimate from the FY2025 annual report (S100XTWY, as of Dec 31, 2025): about 44.6% after removing retail custody and nominee accounts from the 69.3% financial-institution plus foreign-corporation share, and an insider line for MMXX Ventures and Simon Gerovich. Those `floor`, `estimate`, and `insiders` fields live on Metaplanet in `data/institutional-ownership.json` and are kept when the holder list is refreshed. Register names are labeled as register names. A large-shareholding footnote the company says it could not confirm is a note, not a share count. Those PDFs are read with `pdftotext` (poppler). EDINET itself is not called.
- Stock prices & FX: Yahoo Finance chart endpoint (unofficial, keyless). `quote` is the price behind market cap and mNAV. Optional `display_quote` is shown in the Stock price cell only (Metaplanet shows live MPJPY in USD, with the 3350.T regular-session close underneath). If that quote fails, the cell falls back to `quote`.
- BTC price: CoinGecko simple price (falls back to Yahoo BTC-USD).
- Latest filing is a freshness check. CEBE numbers are never replaced with values parsed from a filing.
  - SEC (`filings.source` `"sec"`, or legacy `sec_cik`): EDGAR submissions, `https://data.sec.gov/submissions/CIK##########.json`. The page shows the latest 8-K, 8-K/A, 10-Q, 10-Q/A, 10-K, or 10-K/A (form, date, sec.gov link). It shows “Up to date” when that filing is not newer than the date CEBE’s figures are based on, and a note such as “New 8-K filed Oct 22 — data may not reflect it yet” when it is. The comparison uses the accession number when CEBE’s source cites that filing, otherwise the latest date written in the source, otherwise the as-of date.
  - Metaplanet (`filings.source` `"metaplanet"`): the disclosure list at https://metaplanet.jp/en/shareholders/disclosures (Japanese twin under `/ja/disclosures`). A plain GET returns a server-rendered page. The update reads the embedded disclosures payload (date, title, PDF link). The HTML table is only the first page and does not include the PDF hrefs. Each row is an English or Japanese copy of a TDnet filing. The English list is what the cell counts; a later date that exists only in Japanese still flags. The cell shows the newest disclosure (English title when one is on that date), linked to the PDF on contents.xj-storage.jp or metaplanet.jp, and how many newer disclosures there are. Titles that look like a bitcoin purchase, convertible bond, share issuance, share repurchase, or preferred stock are called out in the note and the shown title is highlighted. The company is flagged when a listed disclosure is dated after the newest TDnet id in CEBE’s `source` text (18 digits beginning with `1401`; digits 5–12 are `YYYYMMDD`). The source currently cites `140120261005546274`, which is 2026-10-05. If the source cites no TDnet id, the comparison uses CEBE’s as-of date.
- EDGAR requests send `User-Agent: BTC Treasury Tracker compound1980@proton.me` and wait at least 1 second between calls (the SEC fair-access limit is 10 requests/second). The CIK is checked against the submissions record (ticker and CIK). The company-ticker file is a cross-check when that file is reachable. If EDGAR is unreachable or a CIK does not verify, that company's cell says the SEC check is unavailable and the rest of the update still succeeds. The Metaplanet page is fetched with a browser User-Agent. If that fetch or parse fails, Metaplanet’s cell says the filing check is unavailable and the rest of the update still succeeds.
